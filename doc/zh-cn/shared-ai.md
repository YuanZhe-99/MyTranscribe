# 共享 AI 接入

MyApps-AI v0.6.0 负责 ASR 运行时、路由、模型包基础设施及在线转写传输。
应用保留记录 ID、任务恢复、FFmpeg 切窗、存储路径与回退偏好。

## 兼容性

应用适配器将已有值类型转换为共享契约。模型包 JSON、路线键与健康指纹
保持兼容。已有模型文件和自检记录应无需重新下载即可使用。
原生运行时版本及哈希由共享版本固定。

## 设置

来源记录仍属于同步配置。下载、引擎健康状态与隐私确认仅在设备本地保存。
API 密钥通过独立的安全 WebDAV 通道交换，不进入备份或 ZIP 导出。任务仍按任务选择来源；共享路由不会替换为另一个模型。

来源与模型记录位于来源分区。下载文件使用共享本地模型条目，在线端点与
密钥使用共享在线编辑器，并注入 MyApps-UI 端点、密钥与连接测试控件。
能力与模板编辑仍可从这些页面进入。设备回退、说话人标注与诊断放入各自
骨架分区。导航保留转写与设置，旧 `/library` 链接转至设置。从新任务打开
设置时，任务表单与选择仍保留在导航栈中。

## 隐私与交换

WebDAV 确认门禁覆盖连接测试、同步、强制传输、冲突完成与自动同步。
在线确认按来源 ID 与服务器 origin 保存。已有任务缺少确认时在上传前
失败，确认后可恢复。两类确认仅保存在 storage_config.json。

密钥使用 `provider` 命名空间及已有 transcribe_secrets.json 格式。
编辑和交换保留条目未知字段，密钥数量不含墓碑。强制密钥上传/下载使用
单向交换。保存公网 HTTP 受信任主机前必须勾选共享风险警告。
EasyTier 使用 `.et.net`。

## 原生实现归属与验证

移除应用本地 ASR 包与两个预构建工作流。MyApps-AI 负责二进制、头文件、
绑定与 hook。已有 release 产物 URL 保持可访问；下载模型不会跟随未固定
的最新版本。FFmpeg 仍由应用管理，本应用不打包 llama 后端。

宿主测试实测 whisper tiny 加载、转写与取消。模拟测试覆盖路由、任务、
传输与安全交换。平台构建不能证明 Windows、Android 或 Apple 真机推理
通过，也不能证明真实在线服务行为已验证。
