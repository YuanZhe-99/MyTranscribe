# 设置 · 数据

四行，各管一件事。

## WebDAV 同步

把应用指向你自己的 WebDAV 服务器，你的来源、模型和偏好就会跟着你到另一台设备。设置之前它是关闭的；设置之后
它也只与你填写的那台服务器通信。

页面上有服务器地址、你的凭据、要使用的文件夹、一个连接测试，以及一个自动同步开关。下面是：立即同步，以及在
一个说明哪一边会丢失的确认之后 —— 强制上传与强制下载。

地址下方的横幅会说明你的 API Key 是否会随其余内容一起走。在 HTTPS 下会，在诸如你自己的网络、Tailscale 或
ZeroTier 这样的私有地址下也会；在通往公共服务器的明文 HTTP 下，你的设置照常同步，密钥留在本机。见
[`secure-secrets-sync.md`](secure-secrets-sync.md)。

当两台设备改了同一样东西时，应用会逐条询问保留哪个版本，同时展示两者以及各自的时间。它绝不替你选择，而中途
退出这个询问会让一切保持原样，而不是应用到一半。

## 备份

你的来源与模型在本设备上的一份副本。随时可以做一份，或者开着每日自动备份并选择保留多久。恢复时会询问要取回
哪些部分，并在写入任何东西之前检查整个文件。

备份从不包含你的 API Key 或你的录音。这在实践中意味着：在全新设备上恢复会拿回你的来源和模型，密钥需要重新
输入一次。

## 导出与导入

内容与备份相同，但是一个你可以放到任何地方的 `.zip` —— 另一台机器、U 盘，或你自己的云端文件夹。导入会替换现
有内容，因此会先确认，并在写入任何一个文件之前验证整个归档。

## 这里没有的东西

你的录音与转写稿。它们留在设备上，每份转写稿在查看器里有自己的导出选项。把几小时的音频经由同步文件夹送出
去，不是应用会悄悄替你做的事。见 [`../data-formats.md`](../data-formats.md)。
