# 来源与模型

*由里程碑 M2 交付。*

一个**来源**是应用可以把音频送去的地方：一个 API 端点、对它的认证方式，以及它提供的模型。用户看到的词是
"来源"；在代码中它叫 provider。

## 内置模板

三个，首次启动时生成：

- **OpenAI** —— 官方 API。
- **OpenRouter** —— 通往众多模型的网关，有自己的请求形态用于服务方特有的选项。
- **OpenAI 兼容** —— 一个空白端点，适用于任何讲同一套协议的服务：本地的 `whisper.cpp` 或
  `faster-whisper` 服务器，或者另一个网关。认证可以完全关闭，这通常正是自己机器上的服务器所需要的。

模板以**派生 id** 生成，因此两台全新设备产生逐字节相同的记录，首次同步会合并它们，而不是留下两份一模一样的
东西。

## 一个模型记录了什么

不只是它的名字。每个模型都带着应用为了决定如何切分录音、以及能向它要什么所需要的信息：

| 字段 | 用途 |
|---|---|
| 上传大小上限 | 单个窗口的字节预算 |
| 时长上限 | 单个窗口的时间预算 |
| 说话人标签 | 是否提供该功能，以及如何请求 |
| 词级时间戳 | 转写稿能否携带它们 |
| 提示词、关键词 | 是否发送用户填写的内容 |
| 语言参数形态 | 有的模型接受列表，有的只接受单个代码 |
| 响应格式 | 该请求哪一种 |
| 输入格式 | 录音能否原样上传 |

一项能力是"支持"、"不支持"，或者**"未知"**。未知是一个真实的答案，不是占位符：对于自定义端点，应用确实不知
道，于是它带着说明提供该功能，而不是把它藏起来或者做出承诺。

## 覆盖

每个字段都可编辑，用户改过的字段会被标记为已覆盖。这在后续版本附带更新的模板时很重要：用户没动过的字段会被
刷新，动过的保持不变。"重置为模板"会清除这些标记并采用新值。

这是应用无法知晓的一切的逃生口。某个服务方提高了上限，某个模型获得了说话人支持，某台自建服务器行为不同 ——
用户改一个字段就能继续，不必等一次发布。

## 导入模型

可以向一个来源索取它自己的模型列表。导入的模型在有匹配模板时带上模板的能力，没有时全部为"未知" —— 应用不做
猜测，因为猜错会变成一个失败的任务和一条让人困惑的消息。

## 本设备

在来源旁边，模型库还存放着**本地模型**：在设备上运行的模型，没有端点，也没有密钥。它们的记录像来源一样同
步；每个模型是否已下载、由哪个处理器运行，则属于设备本身。内置的几个 —— Whisper large-v3 与 turbo、Parakeet
TDT v3、Qwen3-ASR 0.6B —— 以同样的方式、用派生 id 预置，也以同样的方式刷新，保留用户改过的内容。列出、下载
和检查它们的那个区域随第一个引擎一起到来；见 [`local-models.md`](local-models.md)。

## API Key

不属于来源记录。它们放在一个单独的文件里，绝不进入备份或 ZIP 导出，只有在连接符合条件时才会到达另一台设备。
见 [`secure-secrets-sync.md`](secure-secrets-sync.md)。
